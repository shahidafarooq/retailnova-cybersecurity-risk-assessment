# RetailNova Cybersecurity Risk Assessment

## Project Overview

This portfolio project demonstrates a practical approach to identifying, assessing, and prioritising cybersecurity risks in a fictional retail organisation.

RetailNova Pty Ltd is a fictional Australian retail company operating physical stores and online services. The scenario includes cloud infrastructure, e-commerce platforms, payment integrations, customer information, third-party suppliers, and remote employee access.

## Project Objectives

* Identify key cybersecurity risks affecting business operations.
* Assess threats, vulnerabilities, and assets at risk.
* Evaluate inherent and residual risk ratings.
* Recommend security controls and mitigation measures.
* Identify risk owners and monitoring activities.
* Prioritise actions to improve the organisation's security posture.

## Risks Assessed

The assessment covers four key risks:

1. Phishing and credential compromise.
2. Third-party security failure and customer data exposure.
3. Disruption to e-commerce and payment services.
4. Security risks associated with employee-owned devices (BYOD).

## Skills Demonstrated

* Cybersecurity risk identification
* Risk assessment and prioritisation
* Threat and vulnerability analysis
* Security control recommendations
* Risk mitigation planning
* Risk ownership and monitoring
* Cybersecurity report writing

## Key Findings

The assessment identified three risks with High residual ratings and one with a Medium residual rating. It recommends stronger authentication, improved phishing awareness, supplier security assessments, service recovery testing, and better controls for employee-owned devices.

## Project Deliverable

The accompanying Word document contains the full risk assessment, including risk descriptions, existing controls, inherent and residual risk ratings, mitigation recommendations, monitoring activities, and assigned risk owners.
